GitLab Helper

Connect your GitLab instance to see merge requests, to-dos and issues in the sidebar (Alt+Shift+G) or the toolbar popup.

gitlab.com or your self-managed instance.
Use scope read_api; api is only needed to mark to-dos as done. Create a token →
Stored only in this browser's extension storage. This token is the extension's only way into GitLab: it has no access to your GitLab session, cookies or site data.

Bookmarks

Creates “To review” and “My MRs” subfolders, adds new MRs and removes merged or closed ones on every refresh. Bookmarks you add to these folders yourself are left alone. Turning this off keeps the folder as it is.
